# 工作通知

这里是工作类通知的脱敏行动索引入口，只保存通用分类与行动元数据。

可记录日期、不能识别来源的类别、主题类别、行动状态，以及经过脱敏的一句话行动摘要。私人原件保存在个人 Obsidian Vault；请在本地按日期与分类查找。

不要提交姓名、账户、机构、邮箱地址、具体会议事项、邮件正文、附件、身份材料、原始账单或任何凭据与秘密。文件名与链接同样需要脱敏。

每次提交前确认：条目表达的是可以版本管理的行动信息，且无法从内容与字段组合识别私人来源或还原私人通知。

本目录适用根目录的[准入与历史风险说明](../README.md)。当前树中的删除不等于清除历史，历史处理另行开展。
