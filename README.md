# email-knowledge

## 仓库定位

本仓库是经过脱敏的邮件接收元数据与分流索引，用于管理行动状态和知识去向。私人原件保存在个人 Obsidian Vault 的隐私资料层，按日期与分类在本地查找。

GitHub 只保存已脱敏、值得版本管理的材料；邮件原文归档由个人 Obsidian Vault 承担。

## 允许记录

每条索引只可包含以下经过审查的信息：

| 字段 | 要求 |
|---|---|
| 日期 | 使用日期，不补充私人日程细节 |
| 来源／分类 | 使用不能识别个人、账户或机构的类别 |
| 主题类别 | 只写通用事项类别 |
| 行动状态 | 待处理、处理中、已完成或无需行动 |
| 脱敏摘要 | 一句话说明行动，不含身份与私密事项细节 |
| 原件位置提示 | 仅提示“私人原件保存在个人 Obsidian Vault”，不提供可访问的原件链接或敏感路径 |

## 禁止提交

- 发件人或收件人的邮箱地址及其他身份信息。
- 完整邮件正文、附件或附件中的私人内容。
- 凭据、密码、验证码、API 密钥及其他秘密。
- 身份证件、原始账单和私人会议细节。
- 可以结合其他字段重新识别来源的姓名、账户、机构与具体事项组合。

提交前应检查正文、文件名、链接和元数据。无法确认已脱敏的材料保留在个人 Obsidian Vault，待复核后再决定是否提炼索引。

## 分类入口

- [工作通知](工作通知/README.md)：只记录脱敏行动元数据。
- 其他目录沿用现有分类；上述准入边界适用于全部目录。

## 历史风险

从当前分支树中删除文件不会清除 Git 历史、旧提交或备份分支中的内容。本轮仅整理默认分支的当前树，历史清理明确延后，未进行历史重写，也不代表已经完成历史隐私清除。
