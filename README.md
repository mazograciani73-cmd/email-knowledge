# 邮件知识库

这个仓库用来保存从 `bundstory@mail.grokbot.com` 整理过来的邮件，方便人和大语言模型一起查阅。

## 怎么浏览

每个顶层文件夹对应邮件例行任务里的一个类别：

| 文件夹 | 含义 |
| --- | --- |
| `验证码/` | 含验证码、OTP、一次性登录码的邮件 |
| `账单/` | 账单、付款、发票类邮件 |
| `新闻简报/` | 新闻、newsletter、资讯简报 |
| `工作通知/` | 工作相关通知、会议、协作邮件 |
| `其他/` | 以上都不合适时放这里 |

## 单封邮件怎么存

- 每封邮件一个 Markdown 文件。
- 文件名格式：`YYYY-MM-DD_主题或发件人简写.md`（必要时会缩短或去掉特殊字符）。
- 文件正文固定包含这些字段：发件人、日期、主题、类别、正文或中文摘要。

## 给大语言模型的提示

当你被指向这个仓库时：

1. 先读本 README，了解分类。
2. 按任务只打开相关类别文件夹。
3. 每封邮件文件都是独立知识条目，字段齐全，可直接引用。

## 来源

邮件来自 Grok Bot 邮箱 `bundstory@mail.grokbot.com`。分类规则与例行任务「邮箱新邮件总结」一致。
